# Bloque de estilo para Stitch

Generar este bloque a partir del DESIGN.md vigente (no copiar valores obsoletos). Debe caber en un prompt: máximo ~25 líneas. Ejemplo con los valores iniciales:

```
SISTEMA DE DISEÑO DEVMARKET (seguir estrictamente)
Estilo: Light Tech, minimalista y profesional. Fondo blanco, sin modo oscuro.
Colores: primary #2563EB (hover #1D4ED8), secondary #4F46E5 (uso mínimo),
surface #F8FAFC, texto #0F172A, texto secundario #64748B, borde #E2E8F0,
borde de inputs #7F8EA3. Estados: success #16A34A, warning #D97706,
error #DC2626; para texto usar #15803D, #B45309, #B91C1C.
Tipografía: Manrope para títulos, Inter para interfaz y cuerpo.
Layout: ancho máx. 1200 px, espaciado en múltiplos de 8 px.
Radios: tarjetas 12 px, botones e inputs 8 px. Borde 1 px. Sombras sutiles.
Botones principales 44 px de alto. Íconos outline.
Reglas: no inventar funcionalidades, precios, verificaciones ni métricas;
marcar todo dato de ejemplo como «Contenido ficticio»; no mostrar
VerifiedBadge sin verificación completa; separar perfil de desarrollador
y servicio; estados no dependen solo del color.
Al modificar una pantalla existente, conservar lo aprobado.
```

Entregar el bloque en un recuadro de código para copiar, y mencionar qué versión del DESIGN.md lo originó.
